# UI and product polish plan

Рабочий план ближайших правок по "Голосу".

## 1. Окно настроек

- Нижние кнопки всегда видны при маленьком и большом окне.
- Содержимое вкладок прокручивается внутри окна.
- Кнопки внизу компактные: `Перезапустить`, `Ярлыки Windows`, `Сайт`, `Сохранить`, `Закрыть`.
- Длинный русский текст переносится и не уезжает за границы.

## 2. Распознавание

- Профили называются понятными словами:
  - `Локально: базовый баланс`;
  - `Локально: лучше, медленнее`;
  - `Локально: быстро, качество ниже`;
  - `OpenAI напрямую: свой API-ключ`;
  - `Голос Премиум: через наш сервер`.
- OpenAI напрямую использует ключ пользователя на этом компьютере.
- Голос Премиум использует наш сервер и списывает минуты с баланса аккаунта.

## 3. Поддержка вместо диагностики

- Вкладка называется `Поддержка`.
- Поле сервера поддержки скрыто от обычного пользователя.
- Пользователь видит поле сообщения и кнопку отправки обращения.
- Диагностика прикладывается как безопасный технический архив.
- Технические действия остаются внизу: открыть лог, собрать диагностику вручную.

## 4. Автоматическая диагностика

- Добавить отдельный этап с ночной отправкой лёгкого отчёта.
- Нужен явный переключатель согласия пользователя.
- Отправлять можно: версию, профиль, ошибки, состояние запуска.
- Нельзя отправлять: аудио, API-ключи, пароли, приватные токены, текст диктовки.

## 5. Логотип и ярлыки

- Единый логотип используется в окне настроек, трее, меню Пуск и EXE.
- PyInstaller получает `golos.ico`.
- Ярлыки Windows в dev-режиме используют `voice_input/assets/golos.ico`.

## 6. Сайт

- В программе есть ссылка `Сайт`.
- Текущий адрес: `https://golos.msgcrm.ru`.
- Отдельный вход на сайт пока не нужен: личный кабинет живёт внутри программы.
- Сайт остаётся витриной: скачать программу, описание, оферта, политика, поддержка, контакты.

## 7. Юридические документы

- Нужны: оферта, политика обработки персональных данных, условия возврата, реквизиты.
- В программе и на сайте нужно указать, что установка, регистрация или оплата означает согласие с документами.
- Для финальной версии нужны реальные реквизиты исполнителя.

## 8. Персональные данные

- Сейчас хранятся: email, имя, хэш пароля, баланс, платежные ID YooMoney, технические логи.
- Платёжные карты не хранятся в Голосе, они обрабатываются на стороне платёжного сервиса.
- Нужно добавить понятную процедуру удаления или выгрузки данных по запросу пользователя.
